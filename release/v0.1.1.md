# ST Score Audio Engine v0.1.1

Patch release focused on Grand Piano audition latency hardening.

## Changes
- Deduplicates concurrent sample-byte fetches.
- Deduplicates concurrent AudioBuffer decodes.
- Warms manifest-declared preload roots after AudioContext unlock.
- Keeps decoded warmup best-effort and non-blocking.
- Prevents a late raw `prepare()` completion from downgrading a READY engine back to PREPARED.
- Preserves bounded caches, explicit failure behavior, instrument lifecycle gates, and existing audition semantics.

## Versioning
- `@st/score-audio-web`: `0.1.1`
- `@st/score-audio-contracts`: remains `0.1.0` because its public contract version is unchanged.

## Qualification boundaries
- Grand Piano: ACTIVE / QUALIFIED.
- Classical Guitar: SUSPENDED.
- Other scaffold instruments remain UNQUALIFIED.
- This release does not authorize SesliTab production cutover.
