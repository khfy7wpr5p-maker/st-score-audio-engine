# ST Score Audio Engine v0.1.2

Patch release promoting Violin after completion of the P08 qualification gates.

## Changes
- Promotes `VIOLIN` from `SCAFFOLD / UNQUALIFIED` to `ACTIVE / QUALIFIED`.
- Adds the VSCO 2 CE Solo Violin / Arco Vibrato CC0 manifest to the default browser runtime provider.
- Records completed automated WebKit, physical PC, physical Safari/iOS, and physical latency evidence.
- Preserves the existing Grand Piano production path and low-latency warm-cache behavior.
- Keeps Classical Guitar `SUSPENDED` until its own qualification sequence is completed.
- Keeps Viola, Cello, Double Bass, Woodwinds, and Brass scaffold-only.

## Versioning
- `@st/score-audio-web`: `0.1.2`
- `@st/score-audio-contracts`: remains `0.1.0`; public audition contract semantics are unchanged.

## Safety boundaries
- Audio remains noncanonical.
- Host remains responsible for canonical sounding pitch.
- Suspended instruments cannot re-enter production through qualification evidence alone.
- No SesliTab production cutover is authorized by this release.
