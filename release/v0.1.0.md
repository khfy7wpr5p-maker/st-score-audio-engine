# ST Score Audio Engine v0.1.0

First immutable public distribution identity for the ST Score Audio Engine contracts and browser audio runtime.

## Published package identities

- `@st/score-audio-contracts@0.1.0`
- `@st/score-audio-web@0.1.0`

The GitHub Release attaches reproducible package tarballs for both packages, the browser SDK bundle, and `SHA256SUMS.txt`.

## Instrument readiness at v0.1.0

- Grand Piano — `ACTIVE / QUALIFIED`; physical iPhone Safari WebAudio and Score Editor note-touch audition evidence completed.
- Classical Guitar — `SUSPENDED`; code/provenance retained, product integration intentionally paused.
- Violin — `SCAFFOLD / UNQUALIFIED`; VSCO 2 CE qualification candidate only, physical iPhone qualification remains open in Issue #7.
- Viola, Cello, Double Bass, Flute, Oboe, B-flat Clarinet, Bassoon, B-flat Trumpet, French Horn in F, Trombone, Tuba — scaffold registry entries only; no qualified runtime sample is implied.

## Safety boundaries

- This release does not change `st-score-editor-core`.
- Renderer remains presentation/hit-test only and owns no audio or canonical pitch authority.
- Audio audition remains revision-bound and creates no editor history revision.
- REST/non-note selection remains silent.
- Unqualified instruments fail closed with explicit sample-unavailable behavior; no hidden timbre fallback is authorized.
- This release does not authorize a SesliTab production cutover or production deployment.

## Distribution contract

The `v0.1.0` tag is created exactly once by the release workflow. The workflow refuses to overwrite an existing tag or release. Release assets are built from the tagged source and checksummed with SHA-256.
